# 《Agent 开发工程师修炼手册》在线版

一个纯静态网站，用于浏览阅读《Agent 开发工程师修炼手册》全部 21 卷（卷00 导读 + 卷01-19 正文 + 卷20 附录）。

## 怎么打开

**方式一（最简单）**：直接双击 `index.html`，用浏览器打开即可。全部功能（含全文搜索、主题切换、Word 下载）在本地文件模式下均可用。

**方式二（本地服务，推荐给长期使用）**：双击 `启动本地服务.bat`，然后访问 http://127.0.0.1:8791/
（需要本机安装了 Python 3；若 8791 端口被占用，可编辑 bat 文件换一个端口号。）

**方式三（部署上线）**：把整个文件夹上传到任意静态托管（GitHub Pages、Cloudflare Pages、Vercel、对象存储等）即可，无后端依赖。

## 功能

- **首页**：按"导读 → 打地基 → 造器官 → 成系统 → 上战场 → 能力延伸 → 实战附录"七个阶段展示全部卷卡片（含各卷标题数/图数/表数与学习要点）。
- **阅读页**：左侧固定目录（一/二/三级标题，滚动高亮当前所在小节），正文含图、表、代码块、提示框；顶部有阅读进度条；底部可切换上一卷/下一卷。
- **全文搜索**：对全书 21 卷约 2500 个段落/标题段落建索引，支持多关键词（空格分隔）与高亮；搜索结果可直接跳到对应卷的具体小节。
- **深链分享**：任意小节都有锚点，例如 `vol05.html#sec-9` 可直接定位；搜索页支持分享链接 `search.html?q=关键词`。
- **主题切换**：右上角 ◐ 按钮在亮色/暗色间切换，并记忆偏好。
- **Word 版下载**：每卷页顶部有「下载 Word 版」按钮（downloads/ 目录，共 21 份 docx）。
- **移动端适配**：窄屏下自动隐藏侧栏、改用折叠目录，图片自适应宽度。
